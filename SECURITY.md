# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for vulnerabilities such as path traversal, symlink escape, archive bombs, or memory exhaustion. Use GitHub's private vulnerability reporting for this repository (Security → Report a vulnerability). Include a minimal archive or steps to reproduce, the affected version, and your operating system.

We aim to acknowledge reports within a few days and to publish a fix with a changelog entry.
